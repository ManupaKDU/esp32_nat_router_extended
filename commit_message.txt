🎨 Palette: [Add autofocus to lock/unlock forms]

💡 What: Added the HTML5 `autofocus` attribute to the primary password inputs in the lock and unlock UI screens.
🎯 Why: These are single-action forms. Adding `autofocus` immediately places the cursor in the input field when the page loads, reducing user friction by saving an unnecessary click/tap before they can start typing their password.
📸 Before/After: Visual change is simply that the input field has focus upon page load.
♿ Accessibility: Improves keyboard navigation flow by placing focus exactly where the user needs it to complete the action.
